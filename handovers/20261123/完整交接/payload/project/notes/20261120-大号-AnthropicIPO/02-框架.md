## 三、对 Fisher 重点的核实结论

### ① 募资很大、市值是否「超过一万亿美元」

- **募资规模：已核实，很大。** 定价 FWP 与 424B4 封面：公开发行 9.80 亿股 A 类，发行价 $83，总额 **$81,340,000,000**（含老股 23,648,646 股，公司拿不到老股部分）。公司新发 956,351,354 股。另有 30 天超额配售权最多再发 147,000,000 股（全部新股）。
- **同步私募：已核实。** 同步发行 313,253,007 股 **无投票权** Class N，按公开发行价 $83，约 **$26.0 billion**。
- **公司实收（净额）：已核实。** 招股书估计本次公开发行（公司部分）+ 同步私募净募集约 **$104.8 billion**；若超额配售全部行使，约 **$117.0 billion**。
- **「超过一万亿美元」：按发行价、用招股书股本测算，可以成立；但不是招股书原文，更不是 1.5 万亿。**
  - 招股书**没有**写「市值 1 万亿」或「1.5 万亿」。媒体（AP / CNBC）把 fully diluted 或整家公司说成约 $1.5 trillion，**与招股书口径不符，禁止当官方数上图**。
  - 作者按发行价 $83 测算（公式：股数 × $83）：
    - 资本化表「pro forma as adjusted」、会计口径已发行在外：A 类 7,583,103,996 + N 类 **outstanding** 4,789,697,318 = **12,372,801,314** 股 × $83 = **$1,026,942,509,062**（约 **1.03 万亿美元**）。
    - 若把 N 类「已发行但因公益发行由子公司持有、会计上不视为在外」的股份也算进去：A 类 + N 类 issued 5,636,538,278 = 13,219,642,274 股 × $83 = **$1,097,230,308,742**（约 **1.10 万亿美元**）。招股书脚注写明这部分「not considered outstanding for accounting purposes」。
  - **建议上图只用 1.03 万亿美元这一档，并写「作者按发行价测算」和股数口径。** 1.10 万亿容易把子公司持有股算进市值，不建议当主口径。
  - 首日开盘/收盘市值：**待核**（官方价未拿到）。
  - 「史上最大 IPO」：媒体拿 $81.34B 与 SpaceX 比较，**待核历史排名，不上图除非补到来源**。
