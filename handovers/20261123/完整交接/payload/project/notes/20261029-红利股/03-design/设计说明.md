- 同 FOMC 期（1080×1440 CSS → 2160×2880；common.css／inner.css／base.css；米白底＋红＋深蓝）。
- **页眉**：红点＋粗体「阿信学财经」＋竖线＋灰字「理财常识」。

- 来源注明四大行市值为 A+H 口径、媒体统计。

## P2 股息率怎么算
- 定义框 → 深蓝公式条 → 红描边算笔账（举例 0.4 元／10 元／12 元）→ 真实一例（中证银行 4.58%→4.49%）→ 结论「分红不变时，股价越涨，股息率越低」。
- 结论加了「分红不变时」，让结论更严谨（框架原句为「股价越涨，股息率越低」）。
- 脚注：股息率为中证指数公司公布的「计算用股本」口径。

- 深蓝左线小框：分红从哪来（净息差 1.41%、大行 1.31%）。
- 脚注同 P2。
