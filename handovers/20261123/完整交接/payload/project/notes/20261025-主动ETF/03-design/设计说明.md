# 设计说明：20261025-主动ETF（大号·基金科普，4 张）

## 通用规范（沿用 20261024-Meta与AI投入 的大号风格与渲染方式）
- **画布**：1080×1440 CSS，2 倍渲染为 2160×2880（3:4），HTML + 无头 Chrome（render.sh），同时出宽 400 缩略图 thumb_p*.png。
- **样式**：common.css / inner.css 照抄 Meta 期；本期补充 etf.css（【自算】小字、页脚位置）。各页特有样式写在页内 <style>。
- **版心**：左右 76px。页眉 top 78：红点 +「阿信学财经」+ 竖线 + 灰字「基金科普」。页脚 bottom 50：短红线 + 两行灰色免责 + 右下页码 n/4。
- **配色**：米白底 #F7F2E8，红 #C8102E（只用于关键词/关键数字/主动ETF列），深蓝 #1E3A5F，米色块 #EAE3D7 / #E1D9CB。
- **字体**：标题和数字 Noto Sans SC Black；标签 Noto Sans SC Medium；正文 Noto Sans CJK SC。
- **免责（四页统一）**：仅为财经知识分享，不构成任何投资建议，不推荐任何具体产品。基金有风险，投资需谨慎。

## P1 封面
- 胶囊 top 160：● 10月23日开始募集 ● 首批18只（红描边；合规后由「开售」改）。
- **标题** 120px（2×＝240px），行高 1.22，两行，无引号无印章：
  - 第 1 行「主动ETF来了」宽 698px，占可用宽 928 的 **75.2%**；
  - 第 2 行「区别和4个风险」宽 786px，占 **84.7%**，「4个风险」红色。
- 副标题深蓝 46px：基金经理选股，场内买卖。
- 3 张数字卡（第 3 张深蓝底突出）：18只／20亿／约150亿；第 3 张下标灰字「媒体渠道统计」。
- 一行总结「3只首日即提前结束募集。」（「3只」红；合规后改）＋ 深蓝左边线提示框「360亿是上限，不等于流入股市的钱。」
- 缩略图（400 宽）下标题清晰可读。

## P2 三种基金差在哪
- 4 行 × 3 列对比表（10-25「新品」改「新产品」），深蓝表头，主动ETF列红表头 + 浅红底 + 红边框，单元格加粗。
- 表下：年费口径一行 + 两行来源小字（只写规则/文件类别，不写产品或公司名）。

## P3 交易所的4条规矩
- 01–03 米色编号行，04 深蓝行；红框「算笔账」：约110～115元红色加大＋【自算】。
- 来源两行：沪深交易所指引文号与日期；费率口径（管理费1%，托管费0.10%或0.15%）。

## P4 招募书写的4个风险
- 2×2 风险卡（粗标题＋两行解释；10-25 按 Fisher 意见删去「风险 01–04」小标签，正文 119 字）。
- 深蓝描边框「了解时注意3点」，圆点列表（不用勾选框，避免像购买步骤清单）。
- 来源小字 + IOPV 释义（IOPV＝基金份额参考净值，交易时间内发布）。

## 检查
- `./check.sh`：越界、重叠、横向溢出、行首标点、孤字、与页脚距离、封面标题字号与占宽。
- 已知误报（均已目测确认无问题）：
  - OVERLAP「主动ETF来了｜4个风险」：大字号行盒超出行高，字形不重叠；
  - OVERLAP「免责｜页码」：免责段落盒子通栏，右侧留白；
  - ORPHAN「只」「亿」于 18只/20亿：大小字混排基线不同被判为两行，实际同一行（nowrap）。
- 4 张 png 与缩略图均已用 Read 逐张打开检查。
- 敏感词扫描：无「机会」「抄底」「必涨」「收益」；无任何基金公司或产品名。
