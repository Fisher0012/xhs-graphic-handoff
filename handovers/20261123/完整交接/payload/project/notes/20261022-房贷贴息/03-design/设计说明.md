# 03 · 排版设计说明
- 制作方式：HTML + 无头 Chrome 截图（技能默认方式）。共用 common.css，每页一个 p*.html，`./render.sh` 一键重新渲染。CSS 画布 1080×1440，按 2 倍渲染，成品是 **2160×2880** 的 PNG（3:4，比技能要求的下限 1242×1656 更高）。
- 风格：沿用账号已有的视觉风格（参考 /workspace/xhs/gushouplus），米白底 #F7F2E8，藏青主色 #1E3A5F，红色强调 #C8102E。页眉是红点 + 「阿信学财经」 + 竖线 + 灰字「政策解读」，封面有红色描边胶囊标签。标题用 Noto Sans SC Black，关键词标红，副标题藏青。01/02/03 编号色块，最后一块是藏青色。页脚是红色短线 + 灰色风险提示 + 页码。
- 字号：主标题 76px（封面 158px，宽度约 870/1080，超过 80%）；条目标题 42–44px；正文说明 31–34px，约占画布宽度 2.9–3.1%。依据/假设类小字 26px，页脚 21px。**取舍**：技能建议正文 ≥3.5%（约 38px），但那样“误区”和“清单”页每页 4 条放不下，只能拆页、变成 8 张以上。最后选择让条目标题保持 ≥42px（3.9%）、说明文字用 31–34px，压缩到 400px 宽的缩略图看，封面和各页标题都能一眼读懂。
- 渲染后检查记录（每张都打开看过）：
  - 第 1 轮：P1 页脚第二行只剩“为准。”两个字 → 改成手动换行。P2 底部“依据”小字和藏青卡片重叠，气泡里“到/底”被拆开 → 整体上移、缩小卡片间距、在“到底”前手动换行。P5 下方留白太多 → 加大条目内边距，并补一行来源小字。P6 的“收藏这页”离页脚太近 → 收紧条目间距，提示条上移。
  - 第 2 轮：P5 的来源小字贴着第 04 块 → 内边距从 34 改成 28，来源下移。
  - 第 3 轮（合规修改后）：P2“年化”改为“每年补”；“单户贷款额度”改为“可贴息贷款额度”。P5 来源改成泛称后，第二行出现孤立的“（2026.10）” → 手动换行。
  - 最终：6 张图都没有溢出、重叠、豆腐块，也没有标点出现在行首；≤、㎡、×、≈、÷ 等符号都显示正常。
