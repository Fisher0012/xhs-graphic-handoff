# 02 · 图片框架（6 张，竖版 3:4）

结构：封面 1 + 痛点/是什么 1 + 干货 3（条件 / 算笔账 / 误区）+ 总结清单 1。
取舍：没有单独做“结尾求关注页”（技能要求不引导关注）；“误区”和“清单”分开两页，一页讲“别误会”，一页是“能直接截图用的自查步骤”，避免堆字。算账页是本篇收藏核心。

所有页固定元素（不计入正文字数）：
- 页眉：红点 + 「阿信学财经」 + 竖线 + 灰字「政策解读」
- 页脚：红短线 + 风险提示：「仅为政策知识分享，不构成任何贷款或投资建议。政策细则以财政部及经办银行官方公告为准。」
- 页码：右下角「n/6」

## P1 封面
- 作用：钩子 + 全篇预览（清单预览作视觉重点）
- 公式：问题式
- 胶囊标签：● 财政部新政 ● 10月1日起
- 主标题（10 字，2 行）：房贷贴息**1%**（红） / 你能拿到吗？
- 副标题（藏青）：3个条件 + 1笔账 + 4个误区（数字红）
- 清单预览：
  - 01 先对条件｜首套、≤120㎡、≤150万，同时满足
  - 02 再算笔账｜贷100万，5年约少付4.7万（估算）
  - 03 别误会｜不是降息，也不追溯
  - 04（藏青，角标「收藏」）办贷前自查｜4步清单，见最后一页
- 呈现：编号色块列表

## P2 这次贴息，到底是啥？
- 作用：痛点 + 讲清政策本身
- 痛点气泡：网上一会儿说“省5万”，一会儿说“月供少500”，到底听谁的？
- 核心一句：国家替你付一部分房贷利息，**不是银行降利率**。
- 5 个要点卡片：
  - 谁出钱｜财政：中央90% + 地方10%
  - 贴多少｜按贷款本金，每年补 **1个百分点**
  - 贴多久｜最长 **5年**
  - 贴多大｜可贴息贷款额度上限 **100万**（单户）
  - 啥时候｜**2026.10.1** 起新发放的贷款，政策暂定1年
- 来源小字：依据：财金〔2026〕95号（财政部、中国人民银行、金融监管总局，2026.9.29）
- 呈现：气泡 + 2 列卡片

## P3 3个条件，必须同时满足
- 作用：干货① 资格自查
- 01 首套 + 新发放商贷｜新房、二手房都算；首套按当地现行标准认定
- 02 建筑面积 ≤ 120㎡｜含120㎡
- 03 房屋价格 ≤ 150万｜含150万（藏青块）
- 不在范围（灰框）：
  - × 用新贷款置换存量房贷
  - × 纯公积金贷款（组合贷只贴商贷部分）
  - × 保障性住房贷款（已有其他支持，不叠加）
- 呈现：编号列表 + 排除清单

## P4 算笔账：能少付多少利息
- 作用：干货② 对比表（收藏核心）
- 公式条：每月贴息 ≈ 当月贷款余额 × 1% ÷ 12
- 表格（贷款额｜首月约少付｜5年累计约少付）：
  - 50万｜417元｜2.4万
  - 80万｜667元｜3.8万
  - 100万｜833元｜4.7万（藏青高亮）
- 说明：余额越还越少，每月贴息也会逐月变少。官方口径：100万长期贷款，最多累计少付近5万元。
- 假设小字：举例假设：30年等额本息、合同利率3.05%、不提前还款不逾期。估算仅供参考，以银行实际还款计划为准。
- 呈现：公式 + 三行对比表

## P5 4个最容易误会的点
- 作用：干货③ 纠正误区
- 来源小字：依据：财政部等三部门答记者问（2026.9.29）；多家经办银行官方问答（2026.10）
- 01 不是降息｜合同利率不变，5年期满后按原合同利率计息
- 02 不追溯｜10月1日前已放款的不享受；已受理未放款的可问经办行
- 03 组合贷｜只贴商贷部分，公积金部分不贴
- 04 逾期就停（藏青）｜逾期期间不贴，还清欠款后才恢复
- 呈现：编号色块列表

## P6 办贷前，按这4步自查
- 作用：总结清单（可单独截图保存）
- 01 问首套｜按当地标准，你算不算首套
- 02 对面积和总价｜≤120㎡、≤150万，都含本数
- 03 签合同时｜签贴息授权确认书，问清比例、期限、额度
- 04 放款后（藏青）｜留意短信，在手机银行查贴息记录
- 红色提示条：多家银行提示：贴息无需第三方代办，警惕以“贴息”为名的收费和诈骗
- 收藏引导：收藏这页，看房签约时对照用
- 呈现：步骤清单 + 提示条
