## 画布与色彩
- 1080×1440 设计，2× 渲染为 2160×2880；四边版心 40px，顶部 26px，底部风险提示固定在 bottom 16px 附近，需为多行页脚留出间距，避免与底部说明卡重叠。
- 背景 #07090d 渐变，右上蓝光、左侧轻红光，顶部 40px 青色网格渐隐。
- 白色主文字；红色强调 #ff2d3f；数据/公司蓝色 #7fd3ff；重要转折与上涨倍数金色 #f3de9a；警示句和下跌倍数 #ff6b78。

## 字体与层级（px 为 1080 宽设计稿）
- 字体：Noto Sans SC Black 用于标题、人名、强调、倍数；Noto Sans SC Medium 用于正文。
- 顶栏：红色标签 22px Black；栏目 22px；日期 22px Black 蓝色。
- 主标题：108px，line-height 1.04，两行、每行 nowrap；第二行关键钩子为红色。一行能完整且同样醒目才用一行。
- 主副标题间距：26px；副标题 34px Medium，#bdcddd，一行讲清这篇核心。
- 人物主卡：距副标题约 18–20px，高 166px，头像宽 164px；标签 18px，结论 32px Black，补充 22px，行高 1.4。
- 分区标题：27px Black，说明 20px 灰色。

## 表格规范
- v6 为两列：人物、公司变化/关键影响。
- v7 为三列：人物 / 交棒年份；关键变化（提炼为一行，nowrap，不拆词）；离任时市值 → 现在（右侧放大倍数，路径与起算说明叠在倍数下方）。
- 行高由内容自然产生；禁止 height:100% 或 flex 撑满。
- 左侧固定两行：人名一行 Black；公司名 + 年份一行 Medium，用「 · 」连接。
- 右侧数字金色/红色强调；底部小字注明口径和日期；页脚须写明市值美元口径、截至日期、不能归因、不构成投资建议。
- 底部补充卡最多两行，换行只切在完整分句处。
