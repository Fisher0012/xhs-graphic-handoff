## P3｜资本金和贷款，差在哪
- 作用：讲清本篇的核心概念，再算「1元对应多少」
- 主标题：资本金 ≠ 贷款
- 结论一句：这8000亿是给项目当「本钱」，不是借给项目的贷款
- 对比表（两列）

| | 项目资本金 | 贷款 |
|---|---|---|
| 是什么 | 投资者认缴的出资，项目的「本钱」 | 项目借来的钱 |
| 要不要还本付息 | 项目不承担这部分的债务和利息 | 要按约定还本付息 |
| 能不能当资本金 | — | 借贷资金不能算资本金 |
| 比例要求 | 基础设施项目一般最低20% | 银行审查资本金后决定贷多少 |

- 表下小字：依据国发〔2019〕26号
- 算笔账：1元工具资金，对应多少元项目总投资【自算】
  - 国开行　约15.1元（5.5万亿÷3650亿）
  - 进出口银行　超14.1元（逾1.7万亿÷1200亿）
  - 农发行　约13.9元（约4.39万亿÷3150亿）
  - 三家合计　约14.5元　｜　2025年那轮　约14元（约7万亿÷5000亿）
- 说明一行：项目总投资里也包括工具资金本身、项目其他资本金和贷款
- 呈现：上半对比表，下半四行横条（按倍数画）

## P4｜这几个数要说明
- 作用：口径页，层次同前几期（小标题加粗大字＋浅色说明）
- 主标题：这几个数要说明
1. **「投完」是什么意思**：截至2026年10月28日，8000亿元全部完成投放（新华社，据三家政策性银行）。是投放到项目，不是项目已经建成
2. **「项目总投资」不是当年投资**：是所支持项目的总投资额，包括工具资金本身、其他资本金和贷款，不宜和当年固定资产投资直接比较
3. **三家措辞不同**：国开、农发是「涉及项目总投资」，进银是「拉动总投资逾1.7万亿」；「约14.5元」是把三个数直接相加后自算的
4. **投向不能相加**：新兴领域、民间投资、11省三项有交叉；进银只公布占比，没有金额；官方没有三家合计的分领域数
5. **2025年那轮**：5000亿元，支持2300多个项目，项目总投资约7万亿元（国家发展改革委，2025-10-31）。今年8000亿元，多3000亿元【自算】
- 来源行：国家发展改革委；新华社（据国开行、进出口银行、农发行）；2026年政府工作报告；国发〔2019〕26号。数据截至2026-10-28
- 风险提示同上
