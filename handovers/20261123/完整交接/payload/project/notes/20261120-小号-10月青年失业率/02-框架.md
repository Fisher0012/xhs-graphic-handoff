# 02-框架｜3 张（封面 + 走势 + 口径）

自查：封面能看出讲 10 月年轻人失业率且方向是连降；不堆倍数/新低；总结/口径页单独可看懂定义。标题未由用户逐字锁死封面句，按「对象+方向、数字放数据卡」写。

## P1 封面
- 作用：点出对象和方向，三年龄组对比，突出 16—24 岁。
- 主标题（两行，沿用小号 cover2）：10月年轻人失业率 / 连续两个月下降
- 页眉：一图看懂｜城镇调查失业率
- 副题：不含在校生 · 全国城镇 · 2026年10月
- 三卡（突出第一卡）：
  - 17.2% / 16—24岁 / 较上月下降0.8个百分点
  - 7.3% / 25—29岁 / 较上月下降0.1个百分点
  - 3.9% / 30—59岁 / 与上月持平
- 说明卡1：16—24岁、25—29岁都是连续两个月下降；30—59岁已连续4个月稳定在3.9%。
- 说明卡2：同期全国城镇调查失业率 5.1%，比上月下降 0.1 个百分点（11月16日官方发布）。
- 导读：①近4个月怎么走  ②这个口径在统计什么
- 风险提示：本文为统计口径科普，不构成就业或政策建议。
- 形式：大数字三卡 + 两条说明，不堆列表。

## P2 走势
- 作用：近 4 个月路径，变化只用「个百分点」。
- 主标题：近4个月怎么走
- 副题：全国城镇、不含在校生 · 变化看个百分点，不是百分比涨跌
- 16—24岁主线：7月 17.9% → 8月 18.9%（升1.0个百分点）→ 9月 18.0%（降0.9个百分点）→ 10月 17.2%（降0.8个百分点）
- 另两行对照：25—29岁 7.2→7.5→7.4→7.3；30—59岁四个月均为 3.9%
- 说明：7、8月走高，官方称主要受毕业季影响；9月起回落。
- 来源小字：16—24岁、25—29岁各月见澎湃引述统计局分年龄组公布；30—59岁10月及「连续4个月稳定」见统计局 11月16日答记者问；全国城镇调查失业率见统计局 11月16日新闻稿。
- 形式：柱状对比（突出10月）+ 对照表。

## P3 口径
- 作用：讲清定义，纠正「失业率=全部同龄人里没工作的人占比」。
- 主标题：这个口径在统计什么
- 副题：先看懂分母，再看那几个百分比
- 要点1 不含在校生：官方从 2024 年起按月发布不含在校学生的 16—24、25—29、30—59 岁劳动力失业率。把在校生算进去，会把找兼职和毕业后找工作混在一起。
- 要点2 不是全部同龄人的比例：失业率 = 失业人口 ÷ 劳动力人口。在校读书、不找工作或不能马上工作的人，多数不在分母里。所以不能把 17.2% 读成「每100个16—24岁里有17个人没工作」。
- 要点3 怎样才算失业：须同时满足调查参考周内没工作、调查时点前3个月内找过工作、有合适工作能在2周内开始工作（统计局《调查失业率的计算方法》2024-11-15）。只满足「没上班」不够。
- 要点4 两个口径别混：全国城镇调查失业率（10月 5.1%）包含符合定义的在校生；本篇三年龄组是不含在校生的分年龄组数据。
- 风险提示：同上。不写求职建议。
- 形式：四条说明卡。
