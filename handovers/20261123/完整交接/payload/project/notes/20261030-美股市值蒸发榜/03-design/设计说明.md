# 美股单日市值蒸发榜 · 排版设计说明（小号·统计类）

- 尺寸：设计 1080×1440（3:4），headless Chrome @2x 输出 2160×2880；左右边距 66px（6.1%）
- 风格：小号统计类模板（外汇储备前十 / 8000亿金融工具）——墨绿近黑底、白+青绿渐变标题、左上「一图看懂｜美股」、排名数字大号右对齐+下方青绿进度条、底部灰色风险提示一行

- 字号层级：封面标题 104px/行高1.25（两行）；内页标题 84px；小标题 46px 粗体白；说明正文 28px 浅灰 #b9c0c4、行高1.6，条目间分隔线+约46px间距；排名数字 50px；脚注/来源 19–24px；风险提示 20px
