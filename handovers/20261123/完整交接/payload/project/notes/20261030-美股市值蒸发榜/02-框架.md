# 02-框架｜美股单日市值蒸发榜（小号·统计类，4 张）

- 风格：小号统计类（墨绿近黑底、白+青绿渐变标题、左上「一图看懂｜美股」、青绿进度条、底部灰色风险提示一行），参考外汇储备前十、全球GDP二十强
- 单位统一「亿美元」；凡复核/自算的数标「按收盘价计算」
- 每张底部：风险提示：本文信息仅供参考，不构成任何投资建议。

## P2 谷歌这一天｜自己算一遍
- 作用：算笔账页，把「蒸发」怎么算讲清楚
- 主标题：谷歌这一天 / **自己算一遍**
- 副标题：收盘价 × 总股本，A、B、C 三类股合计 · 按收盘价计算
- 算式卡（3 行）：
  - A类+B类：67.15亿股 × 每股少41.07美元 ≈ 2758亿
  - C类：55.79亿股 × 每股少39.57美元 ≈ 2208亿
  - 合计 ≈ **4965亿美元**
- 前后对比：10月28日收盘约3.98万亿 → 10月29日收盘约3.48万亿（总市值约-12.5%）
- 媒体怎么说（对照条）：Yahoo Finance 4820亿｜NBC 约5000亿｜Report.az 4770亿（盘中）
- 小字：B类股不上市，按A类股价计；股本为2026年10月21日数（公司10-Q）；各家差在股本取数和计法
- 呈现：算式卡 + 三条横向对照条

## P3 这张榜有几个规律
- 作用：只摆统计事实，不讲原因
- 主标题：榜单里的 / **几个规律**
- 4 条（小标题 + 一句）：
  1. 前十有7次发生在2026年：另有2025年2次、2024年1次
  2. 英伟达上榜3次：谷歌、苹果各2次，SpaceX、微软、博通各1次
  3. 跌得多≠蒸发多：英伟达2026-06-05只跌6.20%，蒸发超3000亿；Meta 2022-02-03跌26.39%，蒸发约2320亿，不在前十
  4. 超2000亿的单日越来越多：2026年截至10月28日18次，2025年13次，2022年以前0次（Yahoo Finance据Bloomberg）
- 呈现：编号小标题 + 正文；第4条配3根小柱（0 / 13 / 18）

## P4 这几个数要说明（口径页）
- 主标题：这几个数 / **要说明**
- 5 条：
  1. 名义美元，没调通胀：公司市值越大，同样跌幅蒸发越多，早年的大跌在这张榜上排不上
  2. 「蒸发」怎么算：前一交易日收盘市值减当日收盘市值；是账面市值变化，不是现金损失；盘中数字不算
  3. 各家数字为什么不一样：股本取哪天、多类股怎么算、用哪个收盘价都会影响结果；谷歌这次媒体报4770亿–5000亿
  4. 排序依据：按收盘价×股本复核排序（按收盘价计算）；苹果第4和微软第5只差约4亿，英伟达2026-06-05、谷歌2026-07-23各家报数不一
  5. 只算美股上市公司：同一公司可多次上榜；数据截至2026年10月29日美东收盘
- 来源行：CNBC、Yahoo Finance、NBC News、WSJ、Bloomberg、Reuters、Investopedia、Statista、MarketWatch；股本：美国SEC公司报告；股价：纳斯达克、Yahoo Finance
- 呈现：同外汇储备 P4（编号小标题 46px + 正文 28px）
