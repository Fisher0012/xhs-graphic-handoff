# 四张版框架，按Fisher t89u精简

本轮只做封面，其余三张不渲染。封面标题沿用刚提交的两行，不另改选题方向。

1. **封面：伯里做空英伟达 / 为何又减仓一半**。副题“减空仓 ≠ 转看多”，主卡以真人照片、Michael Burry与“《大空头》原型”身份角标呈现。媒体报道NVDA与SMH各卖出原有看跌期权50%；预览需求、融资与折旧三个原始理由。
2. **原始理由：他担心的三件事**。需求持续性：大客户采购快于部署，若放慢投入，订单能否承接？循环融资：供应商支持客户资金、客户再采购芯片，终端现金流能否独立支撑？折旧争议：设备成本分摊更久会降低当年折旧，若赚钱能力衰减更快，利润和投资回报就可能失真。标为伯里观点，产品更新不等于旧芯片报废。用一页三段机制图，不泛泛列标签。
3. **最新事实：强财报回答了什么**。公司披露2027财年第三季度营收1158亿美元/+103%，GAAP净利润653亿美元/+105%，截至2026-10-25。说明本期经营仍强，尚不足以检验未来需求与融资回报。另以监管调查等风险信息说明股价并非仅随本期盈利变动。调查非违法定论，不把不同时间消息拼成单一因果。
4. **减仓与观点：为什么还留一半**。据报道NVDA与SMH看跌各卖50%，纳指100的2027年4月看跌未减，集中一次说清。媒体转述获利，不算实际收益。结论：仍担心长期风险，与减少部分当前敞口并不矛盾；一次盈亏不是整套研究的判决。不另设期权算例。
