# v4 制作前研究（内部，不发 Fisher）

日期：2026-11-10（北京时间）。素材：`refs2/laomai*`、`bench/`（本次用 yt-dlp 下载的公开视频，仅作分析，不进成片）。

## 0. v1–v3 为什么不合格（根因，不是细节）
- 方法错：桌面截图（DPR1，1920 宽）→ 塞进浏览器框 → PIL/ffmpeg 合成。竖屏里整页只能缩成一条窄带，字 12–20px，放大又发虚；所有运动都是「整张图平移/缩放」，没有元素级动画，所以像动态 PPT。
- 构图错：深色舞台上漂一块小白卡，主体面积 <30%，四周大面积空黑（v3 接触表 8–14 秒）。
- 层级错：钩子字高只有画高 4%，章节卡、图卡、标签全偏小。

## 1. 老麦不废话（refs2/laomai.mp4，122s，逐帧 laomai_frames/）可抽取的手法
| 维度 | 实测 | v4 怎么用 |
|---|---|---|
| 界面镜头 | 网页满画幅、原生像素，几乎不缩；正文字高约画高 3%，表格标题 ≈4% | 界面全部矢量重建，正文 ≥38px，标题 ≥52px，组件出血满宽，不用浏览器框缩小 |
| 标注 | 红色圆角框只框 1 个元素（约画宽 27%），描边 4–5px；红箭头从空白处指入；每屏 1 个主标记 | 红框 #E0000E、6px、圆角 18，描边「画出」；同屏 1 个 |
| 转场 | 章内多硬切；章节卡→界面用径向缩放模糊冲入；三维翻页只翻满画幅页面 | 图卡→界面用缩放模糊冲入；界面内用「共享元素展开」（卡片→弹窗）和竖向甩镜；不再用翻页 |
| 文字动效 | 钩子：RGB 色块甩入 0.2s → 色散收敛 0.4s → 金属白持住，字高画高 12–14%；章节卡：粉笔字从残缺「写」到完整 0.3s | 钩子字高 150–210px（画高 8–11%），逐行跟口播遮罩升起；「剪辑」被红粉笔划掉 |
| 构图密度 | 主体占画面 70%+，几乎没有空背景；黑板有真实擦痕质感 | 每帧主体 ≥70%；黑板改程序生成的无缝擦痕纹理（旧贴图有明显平铺重复） |
| 节奏 | 单镜 2.5–3s，单镜内约 1.5s 一个变化；288 字/分 | 0.5–0.8s 一个视觉事件，事件跟口播词落点 |

## 2. 质量标杆（bench/）
1. **Linear · Introducing Dashboards / Pulse**（YouTube 官方，44s/43s，16:9）  
   - 界面是重建的产品 UI，不是录屏；镜头像「机器」一样在三维倾斜的界面平面上漂移，急加速、长减速。  
   - 大量「出血裁切」：只拍 UI 的一块，四周延伸出画；标题卡是短句遮罩升起。  
   - 列表、卡片逐个错落入场，用的是产品自己的动效语言。
2. **Notion · 5 tips for Custom Agents / What Is Notion?**（YouTube Shorts 官方，1080×1920）  
   - 竖屏里 UI 被拆成**单个组件**（输入框、菜单、按钮）重建，放大到占满画宽，组件内文字约画高 2.5%（≈48px）。  
   - 光标很大，点击有反馈；输入框打字机；组件之间靠白底连续过渡，不靠截图拼接。  
   - 文字层：一句一个短语，遮罩升起，红色「✕」标记划掉否定项（“Notion is not a Task tracker”）。
3. **Figma · Edit and generate vectors with the Figma agent**（Shorts，1080×1920）作辅助参考：UI 组件浮在柔和背景上，带大投影，空间感靠景深和阴影。

## 3. 「专业感」来自哪些具体手法（v4 执行清单）
1. **矢量重建界面**：HTML/CSS 1:1 还原 Sphere 真实组件（配色取自 raw_A 帧：主蓝 #2058D9、卡底 #FAFCFE、描边 #E0E4E7、图标底 #E2EBFA、页底 #F8FAFB），字号按手机放大，任何倍率都锐利。
2. **竖屏重排组件**：桌面弹窗是左右布局，竖屏把同一组件上下堆叠（像产品的移动端布局），文字和视觉不变，组件撑满 ~960px 宽。
3. **先全景再细节**：先给分身页整页的三维倾斜全景（让人知道这是一个 Web 工作台、两大模块在同一页），标①②，再让卡片「展开」成弹窗。
4. **三维透视 + 景深**：全景页 rotateX/rotateY 倾斜、背景页模糊压暗。
5. **弹簧/指数缓动**：元素入场 expo.out / back.out(1.4)，镜头 power3.inOut；从不线性。
6. **元素错落入场**：弹窗内容每 60ms 一个依次升起。
7. **光标**：64px 风格化箭头，弧线移动，点击缩放回弹 + 波纹 + click 音效。
8. **遮罩文字**：标题从遮罩下升起；钩子 RGB 色散故障入场。
9. **有质感的背景**：深色段 = 网格 + 光斑 + 颗粒；黑板段 = 程序擦痕纹理；界面段 = 浅色渐变光斑 + 点阵 + 颗粒，和 Sphere 品牌蓝一致。
10. **数据/状态可视化**：「生成形象」= 照片→扫描光→视频效果；「读一段文字」= 占位文本行逐行高亮；「录15秒」= 红色环形进度从 0 走到 15（全片唯一计数，数字来自卡片原文「录制15秒即可完成克隆」）。
11. **排版层级**：模块胶囊（红底白字）> 大标题 > UI 正文 > 字幕；同屏 ≤1 个红框。
12. **轻微运动模糊**：60fps 渲染，相邻两帧混合输出 30fps。

## 4. 渲染方法
- HTML + GSAP 3.15（官方现已免费含插件，可商用）→ puppeteer-core 驱动本机 Chrome，`timeline.seek(t)` 逐帧确定性截图（60fps）→ ffmpeg tmix 合成 30fps + 音频。
- 不用任何截图做界面；唯一位图是产品自带的示例照片（咖啡馆女生，从 raw_A 帧抠出）。
