## 1｜大号｜公积金最多能贷多少：10城最高额度榜
- 角度：给准备买房或换房的上班族讲清楚各大城市公积金到底能贷多少、“最高额度”有哪几层，让他能先算出自己能贷多少、能省多少利息，再去和银行谈商贷。
- 钩子：深圳把所有上浮叠满，家庭最高可贷351万元，排第一；北京夫妻双缴存、买首套，基础额度就有240万元；苏州单人最高150万元，比北京、上海单人都高。
- 关键事实（基础额度：单人/家庭，单位万元）：
  - 北京：首套120/240，可叠加上浮最多+60/+100。来源：北京住建委等三部门通知，2026-08-07。https://gjj.beijing.gov.cn/web/zwgk61/2024zcwj/436433464/436433467/744089355/index.html
  - 上海：首套100/200；缴补充公积金的再+20/+40；多子女+20%、绿建+15%，两项可叠加到35%。来源：上海住建委，2026-02-25，次日施行。https://zjw.sh.gov.cn/gzdt/20260225/92840e7cb47f453096c9b27b83a4808b.html
  - 广州：一人100、两人及以上200；多孩最高+50%，房屋品质最高+30%，两类可叠加。来源：穗公积金中心规字〔2026〕1号，2026-04-30。https://www.gz.gov.cn/gfxwj/sbmgfxwj/gzzfgjjglzx/content/post_10796725.html
  - 深圳：基础70/130，各类上浮累加后最高189/351。来源：凤凰网，2026-07-01（转述深圳 4-30 新政）。https://finance.ifeng.com/c/8uOztuJ5A83 。定稿必须回深圳公积金中心原文核。
  - 济南：90/130，叠加后最高170/240。青岛：90/130，叠加后最高160/240。来源：山东省政府网转大众日报，2026-04-21。http://www.shandong.gov.cn/art/2026/4/21/art_97560_723571.html
  - 重庆：2026-09至2027-08期间100/200，多子女120/240。来源：重庆日报，2026-08-30。https://cqrb.cn/jingji/zixun/2026-08-30/2763095_pc.html
  - 苏州：150/200（6-1起）；成都：单缴80、双缴120；全国超过60城调整过政策。来源：新华社，中国政府网转，2026-06-04。https://www.gov.cn/zhengce/202606/content_7071043.htm
  - 扬州：单缴108、双缴180，阶段性政策，至2026-12-31。来源：金投网转扬州公积金中心，2026-11-10。https://loan.cngold.org/c/2026-11-10/c10870789.html 。定稿回中心原文核。
  - 利率：首套5年以上2.6%、5年及以下2.1%；二套分别为3.075%、2.525%。来源：中央国家机关住房资金管理中心 2026-06-12 https://www.zzz.gov.cn/html/cjwt/cjwt/19263.html ；福州公积金中心 2026-01-15 https://zfgjj.fuzhou.gov.cn/zwgk/gzdt/zyxw/202601/t20260115_5271484.htm
  - 商贷对照：9月新发放个人住房贷款利率约3.1%。来源：央行Q3货币政策执行报告摘要，新浪转，2026-11-11。https://finance.sina.com.cn/money/bank/bank_hydt/2026-11-11/doc-iniykehc2389482.shtml
  - 算账（自算，举例）：贷100万、30年、等额本息，2.6%时月供约4003元，3.1%时约4270元；每月差约267元，30年合计约9.6万元。
- 页面结构：
  - 封面：「公积金最多能贷多少？10城排行」，深圳351万居首。
  - P1：10城“基础额度”榜，按家庭额度排序。
  - P2：10城“叠满上限”榜，分别写清多子女、绿建、补充公积金各加多少。
  - P3：一笔账，同样贷100万，公积金和商贷差约9.6万。
  - P4：能贷多少还要看3个条件：账户余额倍数、缴存年限、还款能力，附自查清单。
- 打分：切5/信5/藏5/时4/安5 + 干货8 = 32。
- 红线：基础额度和叠加上限必须分两列；不说“现在该买房”；不预测房价；不点名楼盘或银行；政策有期限的要标明（扬州、重庆）。

## 2｜大号｜前三季度主要税种增速榜：证券交易印花税+65.1%居首，个税+14.1%，契税和土地增值税各−14.5%
- 角度：给关心钱从哪来、往哪去的普通人讲清楚国家收的税里哪些涨、哪些跌，让他能看懂“个税涨得快”“卖地收入降”分别和自己的工资条、买房、炒股有什么关系。

  - 证券交易印花税2391亿元，+65.1%；印花税合计4121亿元，+31.1%。
  - 个税13464亿元，+14.1%；环保税+18.8%；进口环节增值税、消费税15171亿元，+12.7%；车购税1702亿元，+12.2%；资源税+12.1%。
  - 企业所得税+7.1%；国内增值税55416亿元，+6%。
  - 下降的：消费税−4.1%；契税2884亿元、土地增值税2818亿元，均−14.5%；耕地占用税−6.2%。

- 页面结构：

  - P1：涨幅榜，前八名。
  - P2：跌幅榜，契税、土地增值税、消费税，附土地出让收入−27.9%。

## 3｜大号｜2027年放假一共29天，真正的法定假只有13天
- 角度：给上班族讲清楚2027年哪几天是法定节假日（加班拿3倍工资）、哪几天只是调休（拿2倍工资或者补休），让他能看懂自己的加班费有没有算对，也能提前规划年假拼假。
- 钩子：春节放9天，只有除夕到初三这4天算法定假；全年另有5个周末要补班。
- 关键事实：
  - 2027年安排：元旦1-1至1-3；春节2-5至2-13（9天），1-31、2-14上班；清明4-3至4-5；劳动节5-1至5-5，5-8上班；端午6-9；中秋9-15；国庆10-1至10-7，9-26、10-9上班。来源：国办发明电〔2026〕10号，2026-11-05。https://www.gov.cn/zhengce/content/202611/content_7085101.htm
  - 法定节假日合计13天，其中春节4天（除夕、初一至初三）、劳动节2天，其余各1天、国庆3天。来源：国务院令第795号（2024修订，2025-01-01起施行）。https://www.gov.cn/zhengce/zhengceku/202411/content_6986381.htm
  - 加班费：法定节假日加班不低于300%，不能用补休代替；休息日（包括调休形成的休息日）加班，不能安排补休的不低于200%；日工资=月工资÷21.75。来源：北京市政府网转北京日报，北京三中院法官解答，2024-11-17。https://www.beijing.gov.cn/fuwu/bmfw/sy/jrts/202411/t20241117_3942681.html
  - 自算：放假天数合计3+9+3+5+1+1+7=29天；补班5天。
- 待核：2027年清明当日（4-5）、除夕（2-5）在定稿时用万年历再核一遍。不定时工作制一般不适用加班费，页面上必须写明。
- 页面结构：
  - 封面：「2027放假29天，只有13天是3倍工资」。
  - P1：全年日历，标出法定日、调休日、补班日。
  - P2：每个假期各有几天法定、几天调休，做成对照表。
  - P3：加班费公式加举例。举例：月薪1万元，春节初一加班一天约1379元，初五加班不补休约919元（自算，标“举例”）。
  - P4：年假拼假清单（只列日期组合，不推荐出行产品）。
- 打分：切5/信4/藏5/时4/安5 + 干货8 = 31。
- 红线：不教人规避加班费；不点名企业；例外情形要写明。

## 4｜大号｜国考过审人数7年来首次下降：345万人抢3.57万个岗位
- 角度：给在考公和求职之间犹豫的年轻人讲清楚国考热度的真实变化，以及“过审、确认缴费、实考”三层人数的差别，让他能用对口径判断竞争有多激烈。
- 关键事实：
  - 2027年度国考：网上报名393.5万人，过审345万人；比上年371.8万少26.8万，降7.2%；计划招录3.57万人，比上年少约2400人；竞争比约97:1（上年约98:1）。来源：财新，2026-10-28，引国家公务员局10-26消息。https://www.caixin.com/2026-10-28/102498219.html
  - 2026年度：过审371.8万，约98:1。来源：中国政府网图表，2025-10-26。https://www.gov.cn/zhengce/jiedu/tujie/202510/content_7045753.htm
  - 历年过审人数（2019～2025年度）：137.93、143.7、157.6、212.3、259.7、303.3、341.6万。2024年度约225.2万人实考（这个数来自培训机构的口径，定稿不上封面）。来源：极目新闻，2024-12-01。https://www.ctdsb.net/c1747_202412/2318081.html
  - 报考年龄放宽到18至38周岁，应届硕博放宽到43周岁；笔试11-29。来源：国家公务员局公告，新华网转，2026-10-13。https://www.news.cn/edu/20261013/ce6bf7dc36474dd68ecd90aa8b722f06/c.html
- 页面结构：
  - 封面：「国考人数7年来首次下降」。
  - P1：2019至2027年度过审人数柱状图。
  - P2：招录人数和竞争比的变化。
  - P3：报名、过审、缴费、实考四层漏斗，讲清口径。
  - P4：年龄放宽和基层岗位占比这些规则变化。
- 打分：切3/信4/藏4/时4/安5 + 干货7 = 27。
- 红线：历年数字定稿逐年用国家公务员局或新华社原稿核（财新、极目都是转述）；不点名培训机构；不下“考公热退潮”式的结论；不评价岗位好坏。

## 小号-1｜个人养老金：开户约1.5亿，累计只存了1452亿；今年的额度12-31清零
- 来历：升级自10-23的第2题「个人养老金12000元：按税率档算省多少」。新增的是全国缴存规模数据，以及年底倒计时这个时间点。
- 角度：给已经开户但没存钱的上班族讲清楚“开户不等于省税”，让他按自己的税率档算一算今年要不要存、存多少、最晚哪天存。
- 关键事实：
  - 截至2025年末，个人养老金累计缴存1452亿元。来源：民政部、全国老龄办《2025年度国家老龄事业发展公报》，北京市民政局转中国社会报，2026-08-08。https://mzj.beijing.gov.cn/art/2026/8/8/art_4490_755642.html
  - 按约1.5亿个账户算，户均不足千元。来源：中国证券网，21经济网转，2026-11-03。https://www.21jingji.com/article/20261103/herald/e34c154b58388bb445c6790032d6d79a.html
  - 每年1.2万元的扣除额度当年有效，不滚存；顶格存，10%档最多少缴1200元、20%档2400元、45%档5400元；领取时按3%计税；12月是办理高峰。来源：广州日报大洋网，转广州市社保中心，2026-11-05。https://news.dayoo.com/guangzhou/202611/05/139995_55020738.htm
- 弃用：“约22%有缴存”只在搜索摘要里看到；中国老龄协会页面这次抓取超时，没读到原文，所以不用。
- 页面结构：
  - 封面：「1.5亿人开户，户均不到1000块」。
  - P1：按税率档算账：3%、10%、20%、25%档分别省多少（领取时还要交3%，按净额算）。
  - P2：存钱和填报的时间线：12-31前到账；缴费凭证次月生成后，到个税APP填报。
  - P3：哪些人可能不划算：3%档以下、近期需要用钱的人（钱要锁到退休）。
- 打分：切5/信4/藏5/时5/安4 + 干货8 = 31。
- 红线：不推荐任何个人养老金产品或机构；不承诺收益。
